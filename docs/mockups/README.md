# Mockups

Fuente de verdad visual del MVP (§0 del prompt). Guarda aquí las cuatro imágenes con estos nombres exactos:

| Archivo                       | Contenido                                                    |
| ----------------------------- | ------------------------------------------------------------ |
| `01-cliente-busqueda.png`     | Cliente · buscar prestador (desktop 1440 px + móvil 390 px)  |
| `02-ui-kit.png`               | Design system: catálogo de tokens y componentes, no pantalla |
| `03-cliente-cotizaciones.png` | Cliente · detalle de solicitud y cotizaciones                |
| `04-prestador-panel.png`      | Prestador · panel diario                                     |

Los mockups están en tema oscuro. La app usa el tema claro como principal: de los mockups se
reproducen layout, jerarquía, orden de elementos, microcopy y estados; el color sale de los tokens
de `packages/config/tailwind-preset.ts`. El tema oscuro (opcional) usa la paleta de los mockups.
