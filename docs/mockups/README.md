# Mockups

Fuente de verdad visual del MVP (§0 del prompt): layout, jerarquía, orden de elementos, microcopy,
estados y estilo.

| Archivo                        | Contenido                                                    |
| ------------------------------ | ------------------------------------------------------------ |
| `01-cliente-busqueda.jpeg`     | Cliente · buscar prestador (desktop 1440 px + móvil 390 px)  |
| `02-ui-kit.jpeg`               | Design system: catálogo de tokens y componentes, no pantalla |
| `03-cliente-cotizaciones.jpeg` | Cliente · detalle de solicitud y cotizaciones                |
| `04-prestador-panel.jpeg`      | Prestador · panel diario                                     |

Son JPEG reducidos (llegaron por WhatsApp), no los PNG originales. Las escalas para medir sobre
ellos y todas las medidas tomadas están en [medidas.md](medidas.md).

Los mockups están en tema oscuro. La app usa el tema claro como principal, con el mismo estilo
(bordes de tinta, sombras duras, pastel y naranjo); el tema oscuro, opcional, reproduce los
valores medidos.
